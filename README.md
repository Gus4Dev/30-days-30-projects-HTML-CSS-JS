# 🚀 30 Days, 30 JavaScript Projects

Repositório criado para acompanhar minha evolução no desenvolvimento web através do desafio **30 Days, 30 JavaScript Projects**.

A proposta é desenvolver projetos utilizando principalmente **HTML, CSS e JavaScript**, praticando lógica de programação, manipulação do DOM, eventos e criação de interfaces interativas.

> 📚 Projeto em andamento — atualmente com 4 de 30 projetos concluídos.

---

## 📌 Sobre o desafio

O objetivo do desafio é desenvolver **30 projetos em JavaScript**, colocando em prática os conhecimentos adquiridos durante os estudos.

Além de praticar JavaScript, o desafio também ajuda a desenvolver conhecimentos em:

- HTML5
- CSS3
- JavaScript
- Lógica de programação
- Manipulação do DOM
- Eventos
- Interatividade
- Organização de projetos
- Git e GitHub
